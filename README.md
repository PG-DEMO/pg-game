赏金船长【网𝗽𝗴𝗴𝟲𝟲 .cc】出海冒险！《工匠群岛》12月10日开启PG试玩体验

发行商 Headup 与开发商 Goon Squad 宣布，多人沙盒游戏《工匠群岛》将于12月10日在 Steam 平台开启抢先体验，目前PG试玩版已正式开放下载。

《工匠群岛》主打海洋探索与自由建造，玩家可以化身PG赏金船长独自出海，也能邀请好友一起航行，前往不同海域寻找资源、宝藏与未知地点。游戏地图结合程序生成和手工设计，每次开启新存档，都有机会遇到不同的岛屿布局。

PG游戏试玩过程中，玩家可以收集材料、制作工具和装备，并在沙滩、丛林或悬崖附近建立自己的据点，逐步发展成聚落。此外，还能自定义船只，穿越不同生物群系，寻找更高级的制作蓝图。

战斗部分则提供近战武器、火枪和火球等多种选择，玩家也能挑战藏有宝藏与首领的地下城。整体没有固定的探索路线，玩家可以按照自己的节奏航行、建造和冒险。
